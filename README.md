# PyM Tech — web corporativa de alta resolución

Web HTML/CSS/JS sin dependencias externas, compatible con GitHub Pages y Railway.

- `index.html` — página principal, secciones y formulario de WhatsApp.
- `styles.css` y `script.js` — estilos e interacción.
- `assets/` — imágenes WebP de alta calidad (Q92), conservando exactamente las dimensiones originales.
- `launch.bat` — doble clic para abrir localmente en Windows.
- `launch_server.bat` — requiere Node.js para servir en `http://localhost:8000`.
- `server.js` / `package.json` — servidor Node.js para Railway (`npm start`, puerto `PORT`).

**Nota:** los JPG/PNG originales sin recomprimir se mantienen en el ZIP de respaldo `PyM-Tech_HTML_Launch_Alta_Resolucion.zip`. Aquí se sirven WebP para mantener alta calidad y acelerar carga.
